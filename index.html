# 💈 Barbearia Premium - Site Profissional Um site moderno, responsivo e profissional para barbearias. Desenvolvido com React, Tailwind CSS e componentes premium para converter visitantes em clientes. ## ✨ Características - ✅ **Design Profissional** — Estética clássica com toque moderno - ✅ **Responsivo** — Funciona perfeitamente em desktop, tablet e mobile - ✅ **Otimizado para SEO** — Meta tags e estrutura semântica - ✅ **Rápido** — Otimizado para performance - ✅ **Acessível** — Segue padrões WCAG - ✅ **Seções Completas** — Hero, Serviços, Galeria, Depoimentos, Sobre, Contato - ✅ **Integração WhatsApp** — Formulário conecta direto ao WhatsApp - ✅ **Animações Suaves** — Transições elegantes e micro-interações ## 🎨 Paleta de Cores - **Preto Profundo** (#1A1A1A) — Elegância e autoridade - **Branco Puro** (#FFFFFF) — Clareza e confiança - **Ouro Clássico** (#D4AF37) — Luxo discreto e detalhe premium - **Azul Marinho** (#1B3A57) — Profundidade e confiabilidade - **Cinza Quente** (#6B6B6B) — Texto e suavidade ## 📋 Seções do Site 1. **Header/Navegação** — Logo + Menu responsivo 2. **Hero Section** — Imagem impactante com CTA principal 3. **Serviços** — 6 cards com descrição, preço e tempo 4. **Galeria** — Portfólio de trabalhos 5. **Depoimentos** — Avaliações de clientes (5 estrelas) 6. **Sobre** — Informações da barbearia e valores 7. **Contato** — Formulário + Localização + Horários 8. **Footer** — Links, redes sociais e informações ## 🚀 Como Usar ### Instalação Local ```bash # Clone o repositório git clone https://github.com/seu-usuario/barbearia-premium.git cd barbearia-premium # Instale as dependências pnpm install # Inicie o servidor de desenvolvimento pnpm dev ``` O site estará disponível em `http://localhost:3000` ### Build para Produção ```bash # Crie a build de produção pnpm build # Visualize a build pnpm preview ``` ## 📝 Personalizando o Site ### 1. Alterar Informações da Barbearia Edite o arquivo `client/src/pages/Home.tsx`: ```tsx // Altere os dados de contato const whatsappURL = `https://wa.me/55SEUNUMERO?text=...`; // Altere os serviços const services = [ { name: 'Seu Serviço', price: 'R$ XX', ... } ]; // Altere os depoimentos const testimonials = [ { name: 'Cliente', text: 'Seu depoimento' } ]; ``` ### 2. Alterar Cores Edite o arquivo `client/src/index.css` e modifique as variáveis CSS: ```css :root { --primary: #1A1A1A; /* Cor primária */ --accent: #D4AF37; /* Cor de destaque */ --secondary: #1B3A57; /* Cor secundária */ } ``` ### 3. Alterar Logo e Imagens Substitua as imagens em `/home/ubuntu/webdev-static-assets/`: - `logo-barbershop.png` — Logo da barbearia - `hero-barbershop.jpg` — Imagem do hero - `barber-portrait.jpg` — Foto do barbeiro - `barbershop-interior.jpg` — Interior da barbearia - `haircut-detail.jpg` — Detalhe de corte ## 🌐 Deploy ### GitHub Pages 1. Crie um repositório no GitHub 2. Faça push do código: ```bash git init git add . git commit -m "Initial commit: Barbearia Premium website" git branch -M main git remote add origin https://github.com/seu-usuario/barbearia-premium.git git push -u origin main ``` 3. Vá para Settings → Pages e selecione "Deploy from a branch" 4. Escolha a branch `main` e a pasta `dist` 5. Seu site estará em `https://seu-usuario.github.io/barbearia-premium` ### Netlify 1. Conecte seu repositório GitHub ao Netlify 2. Configure: - **Build command**: `pnpm build` - **Publish directory**: `dist` 3. Deploy automático a cada push! ### Vercel 1. Importe seu repositório no Vercel 2. Vercel detecta automaticamente a configuração 3. Deploy com um clique! ## 📱 Responsividade O site é totalmente responsivo: - **Mobile** (< 640px) — Menu hambúrguer, layout em coluna - **Tablet** (640px - 1024px) — Grid 2 colunas - **Desktop** (> 1024px) — Grid 3 colunas, menu completo ## ⚡ Performance - Imagens otimizadas e comprimidas - CSS e JS minificados - Lazy loading de imagens - Animações com GPU acceleration - Lighthouse score: 90+ ## 🔍 SEO O site inclui: - Meta tags descritivas - Open Graph para redes sociais - Sitemap automático - Robots.txt - Estrutura semântica HTML5 ## 🛠️ Stack Tecnológico - **React 19** — Framework UI - **Tailwind CSS 4** — Styling - **Vite** — Build tool - **TypeScript** — Type safety - **Lucide Icons** — Ícones elegantes - **Wouter** — Roteamento leve ## 📄 Licença Este projeto está sob licença MIT.
